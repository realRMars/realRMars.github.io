Privacy policy

Effective 11 October 2026. This policy describes the current owner-operated Upgrade+ Gaming automation app and its public information website. App support: agent87mars@gmail.com.

Who can use the connected app

The connected automation is operated by its owner for the owner's YouTube channel. This website has no public registration, Google sign-in, account connection, or upload form. Visiting it does not connect your Google account.

Google and YouTube data

The local app uses Google OAuth through n8n's YouTube connector. n8n stores the connection credentials and OAuth tokens needed to make authorised API requests. The verified workflow reads the connected channel's ID, title, and custom URL to confirm its identity.

The installed connector's default permission definitions include YouTube read/manage, upload, and partner/audit scopes. Those definitions are not a verified record of every permission actually granted. Partner and audit features are not used by the current verification workflow, and a permission review remains pending. Future authorised upload workflows may process approved video files, titles, descriptions, thumbnails, visibility choices, and API results. They are not currently enabled.

Use and sharing

Google API data is used for the owner's channel verification and specifically authorised channel workflows. It is not sold or used for advertising, profiling, or training AI models. Requests needed for these features are sent to Google/YouTube; an approved upload would send the selected media and metadata to YouTube. Credentials and private execution data are not published on this website.

Google API use is subject to the Google API Services User Data Policy, including its Limited Use requirements. This policy is not a statement that Google has verified the app.

Local storage and security

The self-hosted n8n instance uses a local SQLite database in a persistent Docker volume on the owner's computer. It stores workflows, account information, connection credentials, and execution history. n8n encrypts credential payloads before database storage; its encryption key is held in the same local n8n data area. This does not mean all database content is encrypted. Access to the computer and its backups must also be protected.

The editor is bound to local loopback rather than exposed by this website. n8n diagnostics and personalisation are configured off. No advertising or external AI service is configured in this n8n instance.

Retention and removal

Workflow definitions and connection credentials persist until the owner removes them. Current global settings save successful, failed, and manual execution history, including relevant inputs and outputs. Finished, unannotated executions become eligible for automatic pruning after 14 days or when history exceeds 10,000 executions. Deletion runs periodically with a safety buffer; running, waiting, and annotated executions have exceptions. These settings are not a guarantee that every copy disappears after exactly 14 days. n8n retention details.

The owner can revoke the app's Google access at Google Account connections and remove the n8n credential. Revoking access or removing a credential does not automatically erase past execution history or separate backups. Data-removal questions can be sent to the support address without including secrets.

This website and its hosting

The website source contains no analytics, tracking scripts, third-party fonts, embedded videos, cookies, or browser-storage features. Ordinary links open the named external service only when you choose them. An email sent to support is handled by the email provider.

When hosted on GitHub Pages, GitHub processes hosting traffic. GitHub states that visitors' IP addresses are logged and stored for security purposes, whether or not visitors are signed in. See GitHub Pages data collection and GitHub's privacy statement. The operator cannot promise that the hosting provider collects no data.

Changes

Material changes to data use will be reflected here before that new use begins, with additional consent where required. The effective date identifies this version.
